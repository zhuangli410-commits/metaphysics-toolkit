# 六爻断卦框架（方法论）

装卦交给工具，这一篇讲装卦之后怎么分析。核心原则：**没有日月建，不断应期。**

## 0. 起卦纪律

- 必须记录起卦日期时间（工具的 `--date` `--time` 参数），日建月建是一切旺衰判断的坐标
- 用户口述卦名可能说错（噬嗑说成贲之类）——**先按六爻阴阳装出正确的卦，再核卦名**，不能盲信口述
- 六次摇卦结果自下而上报：第一次 = 初爻

## 1. 装卦完成后的阅读顺序

1. **卦宫与世应**：卦宫定"我"（六亲基准），世爻=求测人自己，应爻=对方/所测之事
2. **用神选取**：按所问之事取用神（问自身看世爻，问财看妻财，问官看官鬼，问长辈看父母，问子女晚辈看子孙，问兄弟朋友看兄弟）
3. **用神旺衰**：用神在月建、日建下是否当令、得生、临值
4. **动爻**：动爻是用神的变化因素，看动爻与用神的生克关系
5. **应期**：结合旬空、合冲、旺衰推时间窗口

## 2. 三条实用原则

### ① 静卦先看卦象本义
无动爻时，卦名、卦辞、大象传是核心信息源。卦辞直读有时比六爻推演更直接。

### ② 旬空的爻 = "有但没到位"
不要断"没有"，断"还没到"。**出空之日/月应事**（旬空两支出旬、或逢冲之日）。

### ③ 日月建决定应期
- 月建力 > 日建力，但日建对具体应期的触发更细
- 旺者应速、衰者应迟；合待冲、空待出、绝待生
- 用户说"起卦是现在"时，必须核实起卦时刻——可能与会话时间不同

## 3. 旺衰速查

- **月建**：当令者旺，令生者相，令克者死，克令者囚，生令者休
- **日建**：临日建者极旺，受日生者旺，受日克者弱，日冲=暗动或破
- 月日综合判断，冲突时月建为纲

## 4. 常见坑

| 坑 | 后果 | 纠正 |
|---|------|------|
| 卦宫装错 | 六亲全错，满盘皆输 | 泽天夬是**坤宫**不是兑宫；火雷噬嗑是巽宫。工具已内置八宫表 |
| 世应错位 | 主体客体颠倒 | 世隔二位为应；游魂世四应一、归魂世三应六 |
| 旬空断"无" | 把"没到位"断成"没有" | 断"有但未到"，找出空之日 |
| 缺日月建硬断应期 | 应期全靠蒙 | 无日月建就明说只能断象不能断期 |
| 过度解读 | 编造卦里没有的信息 | 有就说有，没有就说没有，断错就认 |

## 5. 输出的诚实性

- 依据不充分时，明说"此卦信息不足以断 X，只能断 Y"
- 断错的案例值得复盘：错在装卦、错在用神选取、还是错在旺衰——分级归因
- 别人回复"我不信"时，通常是你之前的判断有问题：先复查日月建是否取对，再复查卦宫世应
