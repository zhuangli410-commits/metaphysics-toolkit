# 八字格局核对清单（方法论）

排盘之后、下判断之前，按此清单过一遍。核心原则：**不照单全收任何口述格局，一切以排盘为准。**

## 1. 先看盘里"有没有"

判任何格局标签前，先确认构成它的五行**真的在盘里**：

| 口述标签 | 必要条件 | 常见误判 |
|---------|---------|---------|
| 财坏印 | 盘里有印（生我者），且印为用神、被财克伤 | 四柱无印 → 谈不上财坏印，实为**财党杀** |
| 财党杀 | 财旺生官杀 + 官杀克身 + 无印化解 | 与财坏印的区别：无印可坏 |
| 财旺生官（正官格） | 财星成局 + **正官透干**（异性克我） | 透七杀则不是——阴阳定正偏，一步错全盘错 |
| 杀印相生 | 七杀旺攻身 + 印星有力通关 | 有杀无印 = 杀攻身无救 |
| 官杀混杂 | 正官+七杀并见天干 | 藏支不算混杂 |

## 2. 十神正偏的判定（最容易错的地方）

以日干为"我"，**阴阳异同**决定正/偏：

- 克我：异性 = 正官，同性 = 七杀（例：癸阴日主见丙阳火? 不——癸水克丙火，丙是"我克"不是"克我"；克癸者土：戊阳=七杀、己阴=正官）
- 我克：异性 = 正财，同性 = 偏财
- 生我：异性 = 正印，同性 = 偏印
- 我生：异性 = 伤官，同性 = 食神
- 同我：比肩 / 劫财

**写代码或口算前，先把五行阴阳配对列出来，不要边写边想。**

## 3. 身强身弱不能单点判断

- 官杀数量多 ≠ 身弱。要交叉看：印是否有力通关、比劫根气、日主坐支
- 例：癸水日主官杀两现，但时柱辛酉偏印坐禄贴身——金贴身生水，底子就硬
- 月令 > 日支 > 其他：月令是最大的权重项

## 4. 断前事的顺序（用已知信息校准）

1. 排盘
2. 用已知事实校准：职业、家底、学历、健康
3. 断 3-6 条，明确让对方案条反馈"准/不准/半准"
4. 按反馈调整，再断流年
5. **断错就认，不要硬圆。** 硬圆一次，信任清零

### 校准时的高频误判

- **原局无印 ≠ 学历差**：印可能在读书期大运里（未藏乙木=暗印托学业一类）
- **妻宫坐财 ≠ 感情难成**：看妻星落宫与合冲（日支藏财+暗合 = 配偶得位有助）
- **桃花 ≠ 恋爱**：咸池桃花只主暧昧、情欲、魅力；确立关系看正官透干 + 夫宫被合引动
- **刑合要看清**：巳申既是六合又是无恩之刑的组成部分，断健康看刑冲，别只数五行

## 5. 流年流月

- 流月干支 = **节气月**，不是农历；给范围用公历（每月 4-6 号换月）
- 断流年先看岁运组合：身弱逢比劫/禄刃 = 能接住事的年份；羊刃年防磕碰，冲羊刃的月份是全年最凶节点
- 验证方式：让命主对"事业/花钱/感情家庭/健康"四条打分，中了再往流月推

## 6. 大运排法（工具已实现，供理解）

- 阳年男 / 阴年女：顺排（月柱后推）
- 阴年男 / 阳年女：逆排（月柱前推）
- 起运岁数 = 出生日到下一个（顺排）/上一个（逆排）节气的天数 ÷ 3
- 大运 0（出生~起运前）干支常为空，从大运 1 读起
